    RIn.Rename Documentation

    Intro

    RIn.Rename is a lightweight renaming tool with a clean, command-like interface and handy features for renaming objects in scene.

    Features

    • Follows Selection Order: Rename objects while preserving the order in which they are selected.
    • Works with Hidden Objects: Renames hidden scene objects.
    • Command-Based Minimal Interface
    • Real-Time Preview: Shows renaming results in the viewport as you type.
    • Common Renaming Tools: Search & replace, numbering, prefixes/suffixes.
    • Token Support: Use $ for object name, ~~ for collection name.
    • Collection Batch Rename
    • Number objects using sequences from A-Z
    • Name Swapping: Swap the names of two objects.
    • Follow Collection Names: Renames objects to match their collection names.
    • Copy object name to data
    • Copy names from active object
    • Name Mirroring: Copies names from the first half of the selection to the second half
    • Comma Rename: Rename multiple objects simultaneously by separating names with a comma (,).
    • Separator Replacement: Replace separators in names.
    • Insert Text at Specific Positions: Add text at a specified position in object names.
    • Group Comma

    Preferences:

    • Customizable HUD

    Extras (not related to renaming):

    • Selection Mode with Regex Support: Select objects based on regular expression patterns.

    Limitations

    Warning
    • Currently this tool isn’t able to track the selections order of collections and hidden objects if you select them in the outliner.
    • Selection order doesn’t work for for hidden objects

    Numbering

    If there are no numbers in the text input, the tool will automatically append numbers to the names, ensuring each object in Blender’s scene remains unique.

    The default numbering format is .001, which is zero-padded to three digits. Numbering starts at 1, with . as the separator.

    You can configure the default settings for the number of digits and the separator character in the Addon Preferences.

    Follows Selection Order

    When you select or deselect objects in the viewport, this tool keeps track of the selection order. This ensures that when you apply numbering, the numbers follow the exact order in which the objects were selected.

    Tracking inside Outliner

    Object tracking functions correctly when you select objects in the viewport.

    If you select objects in the outliner, it behaves the same way as viewport selection, provided the objects are not hidden.

    However, hidden objects or collections—selectable only through the outliner—are not tracked. This leads to the following implications:

    • When renaming hidden objects or collections, the selection order may not be maintained.
    • Mixing hidden objects or collections with visible objects may result in unexpected order changes.

    Please note that all hidden objects and collections are added last when you run the tool.

    For example, if you select these objects in the outliner: Cube, Cube2 (hidden), Light—the tool will process them in the following order: Cube, Light, Cube2 (hidden). This occurs because hidden objects like Cube2 are not (able to be) tracked until the tool is activated, at which point it detects additional selections in the outliner and appends these items to the end of the list.

    While renaming is still possible, the selection order feature does not apply to hidden objects or collections selected through the outliner.

    Until a solution is found to address this limitation, please be aware of how it currently works.

    Works with Hidden Objects

    You can batch rename hidden objects when selecting them in the outliner. However, as mentioned above, the selection order feature will not apply. Instead, the renaming order will follow their arrangement in the outliner

    Operators

    Operators are special keywords that perform specific operations. Most of these (except replace text, replace separator and comma) must be typed exactly as they are. Operators cannot be mixed or used with other tokens.

    List of operators
    /x (swap two names),
    old_text/new_text (replace text),
    seperator (replace separator),
    d (copy object name to data),
    = (copy name from active object),
    == (name mirroring),
    , (comma rename)
    /. (preferences),
    /? (show helps),

    Case conversions:

    /lo, /low, /lower (covert to lowercase),
    /up, /upper, (covert to uppercase),
    /cap, /capitalize, /title (covert to title case)

    Remove/trim whitespaces: /trim, /strip

    Swap two names: /x
