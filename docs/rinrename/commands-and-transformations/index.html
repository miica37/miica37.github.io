Commands and Transformations

Commands

Section titled “Commands”

Commands are short text instructions you type to tell RinRename what to do.

Tokens like $ and ~1 only expand in name patterns. Most commands below treat the text you give them as plain text. To combine a command with tokens, chain them with | , eg. $_GEO|/up.

List of commands

<suffix_text , <<suffix_text (Add Suffix)
old_text/new_text (Search and Replace)
!old_text/new_text (Search and Replace, opposite case-sensitivity)
^/replacement (Replace non-alphanumeric characters)
^<separatordigitsbrackets^> (Change numbering format)
use_with_other_text^<preserve text^>use_with_other_text (Preserve text)
-n (Remove n characters from the start)
—n (Remove n characters from the end)

/rss (Removes trailing Non-alphanumeric characters)

Slash commands are not case-sensitive, so /UP works like /up.

A different prefix or suffix for each object

Section titled “A different prefix or suffix for each object”

Separate prefixes (or suffixes) with commas to give each object its own. Objects after the end of the list are left unchanged. End the list with * to repeat it:

Selected objects:
>>A_,B_ :
>>A_,B_* :

You can also wrap the list in parentheses and add extra text around it, see Group comma with prefix and suffix.

Remove Characters: -n, —n

Section titled “Remove Characters: -n, —n”

You can remove a certain number of characters from the start or end of a name using -n or —n , where n is a number.

  • -n removes characters from the left of the name.
    • Example: -1 removes the first character, -2 removes the first two, and so on.
  • —n removes characters from the right of the name.
    • Example: —1 removes the last character, —2 removes the last two, and so on.

Add Text: +{text}@{position}

Section titled “Add Text: +{text}@{position}”

Insert text at a specific position in the name using the syntax: +text@position .

  • Example: +hello@3 inserts "hello" after the 3rd character in the name (Cube → Cubhelloe).
  • Without @{position}, the text is inserted at the start, eg. +hello turns Cube into helloCube.

Swap two names: /x

Section titled “Swap two names: /x”

Select exactly two objects and use /x to swap their names.

Replace Non-Alphanumeric Characters: ^/{replacement}

Section titled “Replace Non-Alphanumeric Characters: ^/{replacement}”

Use ^ on the search side of Search and Replace to match every non-alphanumeric character. Letters (of any language) and numbers are always preserved.

This is useful for cleaning names that contain a mixture of spaces, underscores, hyphens, brackets, and other symbols. Here, ^ is a special RInRename token; it does not mean “start of text” as it would in a regular expression.

Common uses:

  • ^/_ replaces matching characters with underscores.
  • ^/- replaces matching characters with hyphens.
  • ^/ removes matching characters.

Group Comma: (…, …)

Section titled “Group Comma: (…, …)”

The group comma command allows you to assign different names to objects based on their collections using a specific syntax:

prefix_text_ ( text_one , text_two , … ) _suffix_text

The parentheses and commas inside them are required.

This command is particularly useful when renaming objects that exist in multiple collections. The grouped names inside the parentheses will be applied to objects within each collection in order.

For example, if you use (text_one, text_two, text_three), the first collection’s objects will be named text_one, text_two, text_three, and the same pattern will repeat for objects in the second collection, then the third, and so on.

This is especially handy for naming objects across collections with similar structures. For instance, if you have Highpoly, Lowpoly, and Cage collections, you can use this command to ensure objects in each collection share consistent naming while keeping their group distinctions.

Syntax: ( name1, name2, … )

How it works:
Section titled “How it works:”
  • Enter a name group in parentheses, like (aaa, bbb).
  • Rinrename applies the names in order to objects in each collection.
  • If the collection has more objects than the group, it repeats the sequence until all objects are named.
* This relies on Preferences > Naming > Reset Numbering on each collection (on by default). With it off, the group repeats across the whole selection instead.

Object name to Data name: /d, /da

Section titled “Object name to Data name: /d, /da”

Use /d to copy each selected object’s name to its data name (eg. the mesh), and /da to do it for every object in the file. Objects whose data can’t be renamed (eg. linked data) are skipped, and the result is reported in Blender’s status bar.

/da removes unused meshes

Before copying, /da deletes every mesh data-block that has no users, so that freed names can be used. The All Object Name → Data Name buttons do the same.

You can also type / or /? to open the help view. When the current selection has objects with writable data names, RIn.Rename shows the same Object Name to Data Name action as a contextual button.

Note: Blender doesn’t keep object and data names in sync when using the standard F2 rename or the Batch Rename tool (Ctrl + F2).

RIn.Rename can also rename mesh data automatically whenever you rename objects: turn on Preferences > Naming > Auto Rename Mesh Data Name.

Viewport Names: /v, /vn and /hvn

Section titled “Viewport Names: /v, /vn and /hvn”

Use /vn to show viewport names for the selected objects, or /hvn to hide them. /v shows Show Viewport Names and Hide Viewport Names buttons instead.

These actions also appear in the / help view when the current selection contains objects.

History: /h, /h1

Section titled “History: /h, /h1”

Commands you apply with multiple items selected are saved to a history (the last 50 commands).

  • /h shows a list of your last 10 commands. Pick one to put it back in the text field.
  • /h1 puts your last command back in the text field.

Reset Selection Order: /r

Section titled “Reset Selection Order: /r”

Type /r to reset the selection order to the order of the items selected in the Outliner (sorted by name). Handy when the tracked selection order doesn’t match what you expect.

Help: / and /?

Section titled “Help: / and /?”

Displays a quick reference list of available tokens and commands, in three groups: Common, Text Transformations and Misc., plus a button to open the reference PDF.

In selection mode, this view also shows smart contextual actions, such as Object Name to Data Name, Show / Hide Viewport Names, and the Rename List Workflow.

In No Selection Mode, this view shows scene-wide actions and the Rename List Workflow for targets such as All Objects and Materials.

/?ref and /?doc open the reference PDF directly.

Handy if you forget a token or want to see what’s available.

Quick Options: /.

Section titled “Quick Options: /.”

Type /. to show the most used preferences right inside the rename dialog: Display, Basic Naming, Numbering, Post-filter, Advanced, and Single Selection. See Preferences.

Text Transformations

Section titled “Text Transformations”

Text transformations change every selected name. They can be chained with other commands, eg. ^/_|/title.

/strip

Section titled “/strip”

The /strip command removes extra whitespace from both the beginning and end of an object’s name.

  • /lstrip ( short form: /ls ) – Removes whitespace from the left side.
  • /rstrip ( short form: /rs ) – Removes whitespace from the right side.

/stripSep

Section titled “/stripSep”

The /stripSep command (where sep stands for separator) goes beyond just trimming whitespace—it removes any non-alphanumeric characters from the start and end of the name: anything that isn’t a letter (of any language) or a number. This includes common separators like -, _, ., and spaces.

Short forms:

  • /ss – Strip from both sides
  • /lss – Strip from the left side
  • /rss – Strip from the right side
Selected Object
/ss:

💡 Note: While the name /stripSep suggests it only targets separators, it’s broader and removes any non-alphanumeric characters.

Uppercase, Lowercase and Title Case: /up, /lo, /title

Section titled “Uppercase, Lowercase and Title Case: /up, /lo, /title”
  • /up converts the whole name to UPPERCASE.
  • /lo converts the whole name to lowercase.
  • /title capitalizes the first letter of every word, eg. hero_left ARM.001 → Hero_Left Arm.001.

Turn on Preferences > Naming > /title ignores all-uppercase words to keep words like ARM or GEO as they are: hero_left ARM.001 → Hero_Left ARM.001.

Capitalize: /cap

Section titled “Capitalize: /cap”

/cap capitalizes the first word that has upper and lower case letters: its first letter becomes uppercase and the rest of that word lowercase. The rest of the name is unchanged, eg. 01_hello world → 01_Hello world.

Camel Case and Pascal Case: /camel, /pascal

Section titled “Camel Case and Pascal Case: /camel, /pascal”

The /camel and /pascal commands convert the core of the name (based on the $ token) and keep the rest, such as leading numbers and .001.

How it works:

  • It extracts the core name using the $ token.
  • It splits the core at -, _, . and spaces, and removes those separators.
  • Each word gets a capital first letter and the rest of the word becomes lowercase. /camel leaves the first word as it is, /pascal capitalizes it too.

Split Camel Case: /sc, /sc:{sep}

Section titled “Split Camel Case: /sc, /sc:{sep}”

The /sc command splits camel case text using a separator. Numbers and runs of capitals are split too.

You can specify the separator like this:

  • /sc:sep
  • /scsep

If no separator is provided, it defaults to the one set in the preferences (Preferences > Naming > Separator, . by default).
