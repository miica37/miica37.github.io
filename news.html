1 month ago

Hey everyone, I have some important updates about Shenya, both for existing buyers and new buyers.

Due to a technical issue on FAB’s side, I wasn’t able to update the original Shenya listing. The system kept blocking the update, so the only solution was to create a new product page and resubmit the character.

This new listing contains an important fix to the character’s skeleton.

If you view Shenya from the top orthographic view, the left and right arms were actually not symmetrical, a mistake I unfortunately overlooked for a long time. This update resolves that issue.

🐇 For Existing Buyers

Please don’t worry, this is not a new product. I’m currently working with the FAB team to transfer all old buyers to the new listing so you can access the updated files without needing to repurchase anything.

It has been 4 days, and I’m still waiting for their update. I’ll post another announcement as soon as I hear back from them.

If you urgently need access or run into any problems, please email me and I’ll help you directly.

🐇 For New Buyers

Since this is a new product, it’s not at 50% sale right now because there’s a 30-day wait before we can apply a discount. I originally applied the discount for Shenya before this happened.

If you were planning to buy Shenya at the discounted price, please feel free to contact me and I’ll work out a solution for you.

Thank you for your understanding, this situation was not planned, and I’m doing my best to minimize the impact.

As always, if you have any questions or issues with my products, feel free to email me anytime. I’ll do everything I can to help.
